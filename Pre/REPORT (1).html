TL;DR. 我们在多模态 long-CoT (avg ~17k tokens) setting 下复现了 4 篇用 LLM 隐空间预测「答题对不对」的论文,并做了对照实验。 四种方法在我们 setting 上的 AUROC 排名: 简单线性 probe @ 中后段层 ≈ Paper 2 LSTM ≈ 0.71 > prefix CoE-C @ c=4096 ≈ 0.62 > full-response CoE-R/C/Mag @ ≈ 0.51-0.59。 论文原始 AUROC 0.65-0.95 的强度没有完全迁移到我们 long-CoT 多模态 setting,但「正确性是中后段隐状态里线性可读」这条核心 claim 成立。

1. 实验设定

1.1 模型

  • 架构: Qwen3-VL-8B (multimodal) — 36 transformer layers + 1 embedding = 共 37 个 hidden state
  • checkpoint: q3-8b-my-sft-roll3-step500 (经 SFT roll3 训练后)
  • 精度: bf16 forward, fp32 几何/probe 计算

1.2 数据

  • 来源: 内部 vision benchmark, q3-8b-my-sft-roll3 的 32 个 split inference 文件
  • 抽样: 100 道 question id (random seed=42), 每题 64 个 independent rollouts → 6400 rollouts
  • 平均 response 长度: ~17,000 tokens (long CoT)
  • 正确率: 18.6% (1184 / 6356, base rate; 44 条 >32k token 被长度门控跳过)
  • 正误标注: LLM-as-judge 输出 (q3-8b-my-sft-roll3-merged-llm_judge-out.jsonl), 不是规则匹配,经过对解析规则的稳健化处理 (覆盖 56,677 条 verdict, 0 conflict)
  • 题目分布: 70 道 mixed-correctness, 30 道 all-wrong, 0 道 all-correct

1.3 硬件 / 软件

  • GPU: 8 × NVIDIA H20 (95 GB each)
  • 框架: PyTorch 2.10 + transformers 4.57.6 (verl-py312 conda env)
  • DP 策略: subprocess.Popen + CUDA_VISIBLE_DEVICES (mp.Process spawn 在 GPU 隔离上不稳定)
  • 典型 wallclock: 单次 8-GPU forward ~1 hour

3. 实验 1 — 直接复现 CoE: 效果远不如论文

3.1 做法

对每条 rollout, forward 一次, 提取所有 37 层 hidden state, 仅对 response token 段做 mean pooling 得到 h_l(L+1, D), 然后按论文公式算 4 个标量 (CoE-R, CoE-C, Mag, Ang)。AUROC 衡量这些标量预测 is_correct 的能力。

3.2 结果

指标AUROC (默认方向)AUROC (反向)取最优论文方向
CoE-R0.5170.4830.517大 → 正确(论文一致)
CoE-C0.4690.5310.531反向
Mag0.4700.5300.530反向
Ang0.4100.5900.590小 → 正确(论文一致)

所有指标 AUROC ∈ [0.51, 0.59], 远低于论文报告的 0.65-0.80。

3.3 分布对照

3.4 控制混淆: Within-question

一个潜在 confounder: 题目难度。难题 (低 acc) 通常 response 更长, 而 long response 的 CoE 跟正确 rollout 的 CoE 可能系统性不同。 我们对 70 道 mixed-correctness 题分别在题内算 AUROC, 然后看 per-question AUROC 分布:

控制题目难度后, 仅 Ang 维持 mean AUROC 0.527, 其他都退化到接近 0.5。说明 Experiment 1 那点微弱信号有相当一部分来自题目级别的 confounder, 真正的 within-question 判别力更弱。

4. 实验 2 — Long-CoT dilution 假说

4.1 假说

论文 sentence-level CoE 公式 h_l = (1/T) Σ_t z_l^t 是 token 维 mean pooling。 T 越大, mean 越接近"中心",几何噪声平均掉, 不同 rollout 的 sentence-level embedding 趋同 → AUROC 退化。

4.2 验证

把 6356 个 rollout 按 response 长度等量分 5 桶 (B1 短 → B5 长), 各桶内独立算 AUROC:

关键观察:

  • B1-B4 (≤21k tokens): -Ang 稳定在 0.56-0.57
  • B5 (>21k tokens): 所有指标都接近 0.5, 信号完全消失
  • 准确率单调下降: 0.244 (B1) → 0.118 (B5), 印证 long response = 多半在 hallucinate

这是 dilution 假说的强证据,直接 motivation 了实验 4 的 prefix CoE sweep。

5. 实验 3 — ST-BoN selection 在 full-CoE 上失效

5.1 设定

ST-BoN 论文的 selection rule: 给定 N 条 rollout 的 F(H), 计算两两距离 D_{ij} = (F^i - F^j)², 对每条算 S^i = mean_{j≠i} D_{ij}, 选 argmin S^i 当 winner。我们用全 response 的 CoE(没用 prefix)做 selection。

每道题 × 每个 N (∈ {4, 8, 16, 32, 64}) × 200 次随机 subsample, 用 4 个 CoE metric 各跑一次 ST-BoN。 基线: random pick / majority vote (用 judge 文件里的 box_answer) / oracle (any-correct-in-N)。

5.2 结果

关键观察 (mixed-only 70 题视角):

  • ST-BoN 各 metric 与 random 几乎重合, gap ≤ 0.02
  • Majority vote(虚线)从始至终高于所有 ST-BoN 变体, 在 N≤32 上稳定领先 +0.02 - +0.04
  • Oracle 跟 majority 之间差距 0.5+, 说明「选不出来」是 picker 而不是 candidate 集合的问题
  • N=64 时 mag 短暂冒到 0.36 (vs random 0.23), 但只有 61 个数据点, SE ~ 0.06, 边际显著

结论: full-CoE 的 selection rule 在我们 setting 上几乎不 work。

6. 实验 4 — Prefix CoE sweep: 找到 sweet spot

6.1 设计 (一次 forward 拿多个 c)

修改 forward pipeline,在同一次 forward里对 response token 段做 cumulative mean,在 20 个 c 检查点 ({16, 32, 64, …, 16384, 24576} + per-rollout response_len) 各算一次 CoE。每条 rollout 多记 ~120 个浮点, 整体存储增加 1 MB。 GPU 时间增加 ≈ +10%。

checkpoints (固定 c) = [16, 32, 64, 128, 192, 256, 384, 512, 768,
                       1024, 1536, 2048, 3072, 4096, 6144, 8192, 12288, 16384, 24576]
                       + 每条 rollout 自己的 response_len

6.2 单样本判别 — AUROC 倒 U 曲线

关键观察:

  • AUROC 呈倒 U 形, c≈2k-4k 是 sweet spot
  • CoE-C / Mag 在 c=4096 达到 0.622-0.623, 比 full (0.530) 高 +0.09
  • 4k tokens ≈ 我们 avg response 17k 的 24%, 跟论文「c ≈ 10-20% of T」直觉吻合
  • Ang 峰值更靠前(c≈768, ~5%), 说明角度信号「决定方向」快, 幅度信号「展开」慢
  • c=24576 时 AUROC 反弹但只有 432 rollout(最长那 7%), 噪声大

6.3 ST-BoN selection 在 prefix CoE 上

关键观察:

  • N≤32 时 ST-BoN 仍然在 random 和 majority 之间徘徊, 没显著超过 majority
  • N=64 时 mag/coe_c @ c=384 短暂冒头到 0.36 (vs majority 0.31), 但只有 61 trial, 边际显著
  • 结论: prefix-CoE 改善了「单样本判别」(实验 6.2),但没有显著改善「多样本 selection」
判别 vs selection 的不对称: AUROC 衡量的是跨题把对 vs 错 rollout 排开的能力; ST-BoN selection 衡量的是同题从 N 条里挑 winner 的能力。两者数学上不等价 — 一个 metric 跨题排序好不代表它能在 题内挑 winner。我们的实验是这个不对称的实证案例。

7. 实验 5 — Hidden state probes (Paper 1 / Paper 2)

7.1 数据提取

新一轮 forward, 提取每条 rollout 的 response 最后一个 token(我们追加的 <|im_end|>) 在 37 层的 hidden state, 形状 (37, 4096) fp16。总存储 1.5 GB。

7.2 Paper 1 — Linear / MLP probe

训练 logistic regression / 2 层 MLP probe 预测 is_correct, 5-fold CV by question (避免同题 rollout 泄漏)。 class_weight="balanced" 处理 18.6% 正例不均衡。

关键 ablation: 把 linear probe 在 37 层各自训一遍 (paper 1 主线只用 top layer, 但同期 SAE 和 mech-interp 工作普遍指出 中间层信号最强):

关键观察:

  • Layer 0 (embedding) AUROC = 0.5 严格相等 — 因为所有 rollout 共享同一个 EOS embedding
  • Layer 1 起就有 0.65 — 第一层 transformer 已经把 prompt 信息编码进 last-tok
  • 峰值: Layer 29 (中后段) AUROC = 0.705 ± 0.066
  • Top layer (36) AUROC = 0.686, 略低于 layer 29
  • 这跟 probe 文献一致 — top layer 已经 commit 到 vocabulary, 中后段还在加工高级语义

7.3 Paper 2 — Kinematic + LSTM

Kinematic descriptors (无训练, 跟 CoE 直接对照): 在 last-token 跨层算 velocity_l = ||d_l||₂, acceleration, jerk, curvature, arc_length 等标量 (paper 2 原 motivation 是看这些 hand-crafted 描述符够不够, 结论是有信号但不稳定)。

FeatureAUROC (best dir)
velocity_mean (-)0.600
arc_length (-)0.600
jerk_max (-)0.598
curv_max (-)0.563
......

velocity_mean = mean(||h_{l+1}[last_tok] - h_l[last_tok]||) 本质上就是 CoE-Mag 在 last-token 而不是 mean over response。 0.600 比 CoE-Mag@full (0.530) 高一些, 反映 last-token 表征比 mean 更纯净。但还是远不及监督 probe (0.71)。

LSTM probe (paper 2 主方法, 简化为 last-token only): 在 last-token 的 36 个层间位移序列 (L=36, D=4096) 上跑 LSTM (hidden=128, layers=2), 5-fold CV。AUROC = 0.706 ± 0.076。 跟 best-layer linear probe 几乎打平, 没显著提升。

8.2 五条结论

  1. Long-CoT 稀释了 hand-crafted 几何信号。从 0.62 (prefix) 到 0.51 (full), 损失 +0.11 AUROC, print B5 (>21k tokens) 桶上所有指标接近 0.5, 印证 dilution。
  2. 监督 probe 比所有 unsupervised 强 ~+0.10。线性 probe(sklearn 100 LOC)在 layer 29 上达到 0.71, 明显胜过最强的 prefix-CoE (0.62)。
  3. 「正确性方向」在中后段 (layer 29) 而不是 top layer。这跟 probe 文献的一般规律一致, 也回应了 Paper 1 默认用 top layer 这个未做 ablation 的隐性假设。
  4. 序列建模 (LSTM) 没有显著超过单层 linear。说明信号集中在某个特定层, 而非分布在 trajectory 形状里。 Paper 2 在常识 QA 上 LSTM 优势 ~+5pt, 但简化到我们 last-token only 后这个优势消失。
  5. 判别能力 ≠ selection 能力。实验 4 中 prefix-CoE 把 AUROC 从 0.53 拉到 0.62, 但 ST-BoN selection 只小幅改善, 仍打不过 majority vote。说明跨题 ranking 强不代表同题 cluster 紧。
